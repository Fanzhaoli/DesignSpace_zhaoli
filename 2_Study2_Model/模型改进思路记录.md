## 1. 问题的起点

具体来说，实证数据会计算 Cohen's d（自我 vs 陌生人的反应时和准确率差异），我们希望模型模拟出来的数据也能产生类似的效应大小。

### 1.1 最初的模型

原始模型的漂移率计算大概是这个样子：

```
v = v_T * v_P * v_multiplier
v_self = v * (1 + alpha1)
v_stranger = v * (1 + alpha2)
```

其中 alpha1 控制自我条件的漂移率调整，alpha2 控制陌生人条件。一开始的参数是 alpha1=1.5, alpha2=-0.4，v_multiplier=2.0。
跑出来的结果，d_RT 的平均绝对误差有 0.38，d_ACC 的误差有 0.39。模型预测和真实数据相差较远。

## 2. 第一次尝试：test_d6_fix（修复D6问题）

### 2.1 问题的发现

D6是 P=120, T=500, W=1500，实证数据显示 d_RT=0.306，但模型预测过高。

### 2.2 尝试的几种方案
我尝试了三种不同的改进思路：

**方案一：添加漂移率上限 v_max=2.5**
直接给漂移率设置一个上限，防止它跑太高。就是模型预测出来的 v 值如果太大，就强行截断。

**方案二：放宽上限 + 增加噪声 v_max=3.0 + noise=1.2**
稍微放宽上限，但同时增加一点随机噪声，让结果有更多变化，不那么极端。

**方案三：综合调整 BETA1=0.3 + noise=1.2 + v_max=2.5**
这个方案综合调整了三个参数：
- BETA1 调整到 0.3，影响边界 a 的计算
- 添加 noise=1.2 的噪声缩放
- 设置 v_max=2.5 的漂移率上限

### 2.3 结果对比
| 方案 | D6 d_RT 预测 | D6 d_RT 实证 | D6 误差 | 整体 d_RT MAE |
| 方案一 (v_max=2.5) | 2.11 | 0.306 | 1.804 | 0.382 |
| 方案二 (v_max=3.0 + noise=1.2) | 1.85 | 0.306 | 1.544 | 0.35 |
| 方案三 (BETA1=0.3 + noise=1.2 + v_max=2.5) | 0.45 | 0.306 | 0.144 | ~0.15 |

**方案三效果最好！** 综合调整三个参数之后，D6 的预测从误差 1.8 降到了 0.14，整体误差也大幅下降。
但虽然 D6 变好了，D3a 的问题反而突出了——D3a 的 Cohen's d RT 结果差异变得比较大。所以还需要继续调整。

## 3. 第二次尝试：Parameter grid search（参数网格搜索）

### 3.1 思路
在尝试了 D6 修复之后，我想系统地探索一下整体的最优参数组合。在较大的参数空间里穷举，看看能不能找到一个对所有设计都比较好的组合。

### 3.2 搜索的参数范围
```
alpha1: [0.3, 0.5, 0.7, 0.9]
alpha2: [-0.5, -0.4, -0.3, -0.2]
v_multiplier: [1.5, 2.0, 2.5, 3.0]
v_max: [2.0, 2.5, 3.0, 3.5]
beta1: [0.1, 0.2, 0.3, 0.4]
```
### 3.3 结果

参数网格搜索的结果不太理想。虽然能找到一些相对较好的参数组合，但总有某一个或两个设计的误差特别大。

**最优组合的结果：**
| Design | d_RT 预测 | d_RT 实证 | 误差 |
|--------|-----------|-----------|------|
| D1 | 0.894 | 0.005 | **0.889** |
| D2 | 0.15 | -0.014 | 0.164 |
| D3a | 0.28 | -0.044 | 0.324 |
| D3b | 0.15 | 0.045 | 0.105 |
| D4a | 0.25 | 0.203 | 0.047 |
| D5 | 0.42 | 0.349 | 0.071 |
| D6 | 0.35 | 0.306 | 0.044 |

### 3.4 主要问题：D1 的 d_RT 误差太大

D1 的误差达到了 0.889，实证数据显示 D1 的 d_RT 几乎为 0（0.005），即在 D1 这个设计里，自我和陌生人的反应时间几乎没有差异。
但模型怎预测不出来这个"无差异"的状态，要么正太多，要么负太多。

问题的核心：不是某个参数调不好，而是模型的**结构**可能需要改进。简单地调整几个参数，用处不大。

## 4. 第三次尝试：T 依赖的 ALPHA

### 4.1 思路
也许问题不在于参数值，而在于参数应该随实验条件变化。比如 T（刺激呈现时间）可能对 alpha 有影响——短时自我优势小，长时自我优势大。
让 alpha1 和 alpha2 随 T 变化，用一个高斯函数来模拟"倒 U 型"关系：

```
alpha1 = alpha1_base * exp(-((T - T_center)^2) / (2 * T_width^2))
```

### 4.2 结果
| 指标 | 值 |
|------|-----|
| d_RT MAE | 0.267 |
| d_ACC MAE | 0.196 |

比之前的版本好了，但 d_ACC 的误差还是比较大。

## 5. 第四次尝试：引入 P 和 T 的交互

### 5.1 思路
P（练习）和 T（呈现时间）可能不是独立影响 alpha 的，而是有交互。于是我设计了一个 P-T 交互的公式：

```
alpha1 = alpha1_base * t_effect(T) * (1 + p_effect(P))
```

### 5.2 结果

| 指标 | 值 | 改进幅度 |
|------|-----|---------|
| d_RT MAE | 0.241 | 比 T 依赖版本 ↓ 10% |
| d_ACC MAE | 0.168 | 比 T 依赖版本 ↓ 14% |

确实有改善，但问题也很明显：

**高 P 设计（D3a、D4a）预测过度**：模型预测的 d_RT 远高于实证数据

我觉得：**是不是 P 效应的方向搞反了？**

## 6. 第五次尝试：减弱甚至移除 P 效应

### 6.1 思路
在分析实证数据时，我发现：SPE和练习次数 P 之间并不是简单的线性关系。
| P 值 | d_RT 平均值 |
|------|-------------|
| 0    | -0.0045     |
| 8    | **0.3490**  |
| 120  | 0.1275      |

**实际上是一个倒 U 型曲线！**
- P=0（无练习）：自我优势很小（几乎为 0）
- P=8（少量练习）：自我优势最大（0.349）
- P=120（大量练习）：自我优势中等（0.1275）

不过在建模时，我尝试了各种方式都没能很好地捕捉这个倒 U 型关系。最后发现，直接移除 P 效应（让 alpha1_p_scale = 0）反而能得到更好的整体预测效果。
```
alpha1_p_scale = 0.0  # 完全移除 P 效应
```
### 6.2 结果
| 指标 | 值 |
|------|-----|
| d_RT MAE | **0.128** |
| d_ACC MAE | 0.213 |

**d_RT 的误差降到了 0.128！** 比之前所有版本都好！

也许：
1. 练习效应不是体现在漂移率上的
2. 练习可能让人更熟练，但这种熟练对自我和陌生人条件是同等的
3. 真正的自我优势（alpha）可能主要是由 T（刺激呈现时间）决定的

## 7. 第六次尝试：设计特异性修正

### 7.1 思路

减弱 P 效应之后，还是有一些设计预测不准：
- D5 的 d_RT 预测偏低（差 -0.32）
- D3b 的 d_ACC 预测偏高（差 +0.30）

尝试给特定设计加一个修正系数：

```
alpha1_corrected = alpha1 * (1 + design_correction)
```

### 7.2 结果

加了设计修正之后，某些设计的预测确实变好了，但整体误差反而上升了：

| 指标 | 无修正 | 有修正 |
|------|--------|--------|
| d_RT MAE | 0.128 | 0.221 |
| d_ACC MAE | 0.213 | 0.181 |

看来无法追求每个设计都完美匹配，这样容易过拟合。设计修正虽然让某些设计预测更准，但损害了模型的普遍性。

## 8. 目前的最佳模型

综合所有尝试，目前表现最好的模型参数是：

```
alpha1_base = 0.3
alpha1_p_scale = 0.0  # 移除 P 效应
alpha2_base = -0.2
alpha2_p_scale = 0.2
v_multiplier = 1.5
v_max = 2.5
beta1 = 0.2
```

用这些参数，d_RT MAE = 0.128，d_ACC MAE = 0.213。

### 8.1 各设计预测效果

| Design | P   | T    | d_RT预测 | d_RT实证 | 误差 | d_ACC预测 | d_ACC实证 | 误差 |
|--------|------|------|----------|----------|------|-----------|-----------|------|
| D1     | 0   | 30   | -0.255   | 0.005    | -0.26 | 0.000     | 0.007     | -0.01 |
| D2     | 0   | 30   | -0.003   | -0.014   | 0.01 | 0.020     | 0.289     | -0.27 |
| D3a    | 120 | 30   | 0.192    | -0.044   | 0.24 | 0.528     | 0.212     | 0.32 |
| D3b    | 120 | 30   | 0.018    | 0.045    | -0.03 | 0.181     | 0.479     | -0.30 |
| D4a    | 120 | 80   | 0.189    | 0.203    | -0.01 | 0.511     | 0.426     | 0.09 |
| D5     | 8   | 100  | 0.031    | 0.349    | -0.32 | 0.041     | 0.419     | -0.38 |
| D6     | 120 | 500  | 0.337    | 0.306    | 0.03 | 0.225     | 0.088     | 0.14 |

### 8.2 哪些设计预测得好

- D4a：T=80 中等呈现时间，预测非常准确
- D6：T=500 长呈现时间，预测也不错
- D1 和 D2：虽然有误差，但方向和大小基本合理

### 8.3 哪些设计预测得差

- **D5（P=8, T=100）**：这是最差距大的设计。实证数据显示 d_RT 高达 0.349，但模型预测只有 0.031。
- **D3a 和 D3b**：这两个的 d_ACC 预测都不太准，误差在 0.3 左右。

## 9. 为什么模型预测和实证有差距

可能有几个原因：

**1. 模型太简化了**
真实的大脑认知过程比 DDM 模拟的复杂得多。模型只有 v（漂移率）一个参数在变，但真实情况可能是不同设计的策略不同。

**2. P 效应的机制不清楚**
我一直假设练习会增强自我优势，但实证数据显示P和SPE之间是倒 U 型关系。

**3. D1 的"无差异"状态特别难模拟**
实证显示 D1 的 d_RT 几乎为 0，但模型怎么调都很难精确复现这个状态。

### 9.1 D5 为什么特殊

D5 是所有设计中最特殊的：
- P=8（不是 0 也不是 120，是中间值）
- T=100（较长呈现时间）
- W=1100（很长反应窗口）
- 实证显示极高的 d_RT（0.349）

 D5 可能代表了一种"最优"实验条件，模型可能缺少捕捉这种最优条件的机制。
